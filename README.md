# 💱 Live Currency Analytics Dashboard

An interactive and data-driven forex analytics dashboard built with Python, Streamlit, and Plotly.

This application fetches real-time and historical exchange rate data from the Frankfurter API and provides advanced financial visualizations including volatility analysis, moving averages, Bollinger Bands, correlation heatmaps, and comparative currency performance tracking.

---

## ✨ Features

### 📊 Real-Time Exchange Rates
- USD/TRY
- EUR/TRY
- GBP/TRY

### 📈 Financial Analytics
- 90-Day Historical Trend Analysis
- Daily Percentage Change
- Moving Averages (MA7 / MA30)
- Bollinger Bands
- Rolling Volatility Analysis
- Currency Correlation Heatmap
- Histogram Distribution Analysis

### ⚡ Interactive Dashboard
- Fully interactive Plotly visualizations
- Responsive Streamlit layout
- Auto-refreshable live data
- Clean KPI cards and analytics sections

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/currency-dashboard-streamlit.git
cd currency-dashboard-streamlit
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
